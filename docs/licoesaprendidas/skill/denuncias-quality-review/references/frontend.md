# Frontend

Preserve standalone components, signals e wizard mobile-first. Cruze modelo, defaults, formulário, revisão, FormData e client. Teste loading, erro, retry, protocolo inválido e reset.

Playwright atual intercepta a API e não prova BFF/live. Para UI, combine unidade/componente, E2E mockado, axe e manual WCAG 2.2 AA: teclado, foco, labels, erro anunciado, contraste, zoom/reflow, target e leitor de tela.

Evite DOM direto, innerHTML não confiável e bypassSecurityTrust. Avalie CSP/Trusted Types na infraestrutura. Não envie/persista PII em analytics, logs ou storage.
