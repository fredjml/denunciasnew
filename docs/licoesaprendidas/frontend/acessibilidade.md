# Checklist WCAG 2.2 AA e UX

- [ ] landmark, heading e ordem semântica;
- [ ] nome/papel/valor e label programático;
- [ ] teclado completo, sem trap, ordem lógica;
- [ ] foco visível, movido após mudança e não oculto;
- [ ] erro identificado, associado e anunciado;
- [ ] instrução não depende só de cor/posição;
- [ ] contraste de texto, componente e foco;
- [ ] zoom 200%, reflow 320 CSS px e texto 400%;
- [ ] target size e alternativas a gesto/drag;
- [ ] timeout/mídia/microfone com controles;
- [ ] reduced motion e orientação quando aplicável;
- [ ] estado loading/sucesso/erro em live region apropriada;
- [ ] leitor de tela e browser definidos na matriz de suporte.

Automação axe é baseline; registre violações, impacto e exceções. Teste manual com teclado e tecnologia assistiva continua obrigatório para mudança relevante.
