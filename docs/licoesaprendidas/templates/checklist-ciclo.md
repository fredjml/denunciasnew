# Checklist do ciclo — template

## Antes/durante análise

- [ ] fonte, AGENTS, Git e dados;
- [ ] requisitos atômicos, confiança e contraprova;
- [ ] tools/MCP/owners/fallback;
- [ ] GO/GO COM RISCOS/NO-GO.

## Antes/durante implementação

- [ ] DoR e fatia vertical;
- [ ] teste/evidence plan/rollback;
- [ ] menor mudança/validação;
- [ ] estado atualizado só após observação.

## Teste/review

- [ ] modos e fixtures separados;
- [ ] fonte primária reaberta;
- [ ] diff/untracked/segredos/PII;
- [ ] review adversarial e risco residual.

## Entrega/pós

- [ ] DoD, target e autorização;
- [ ] artifact/publicação verificados;
- [ ] aceite, métricas e post-mortem;
- [ ] lição convertida em controle proposto.
